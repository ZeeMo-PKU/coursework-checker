# GitHub Repository Organization Plan

Owner: `ZeeMo-PKU`

Naming rule:

- Public tools and projects: lowercase kebab-case.
- PKU coursework/material repos: `pku-...`.
- Codex-related repos: `codex-...`.
- MyGo-related repos: `mygo-...`.
- Forks keep their upstream name unless there is a strong reason to rename.
